# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.0.0] — 2026-09-29

Первая версия форка [nick-vels/skills](https://github.com/nick-vels/skills) с кроссплатформенной работой.

### Добавлено
- CI на Windows, Ubuntu и macOS: flake8, тесты, проверка путей (`.github/workflows/verify.yml`).
- Переносимый `tools/measure-run.py` (обработка путей Windows, Linux и macOS).
- Нативные тесты корней проекта для трёх систем (`tests/test_native_runtime.py`).
- ADR 0001–0006: решения по путям, жизненному циклу сервера дашборда, состоянию, CI и публикации.

### Изменено
- `sync.py` работает на Windows: проверка процессов через PowerShell вместо `ps`, безопасное сравнение каталогов.
- Дашборд обновляет только изменившееся: обращения к DOM на тике — 0 вместо 15000 в замере (457 мс против 712 мс).
- Если процесс сервера проверить нельзя, второй сервер не запускается, а запись о нём сохраняется.

### Исправлено
- Дублирование серверов дашборда при недоступной проверке процессов.
- Пути проекта и логов больше не зависят от текущего каталога.
