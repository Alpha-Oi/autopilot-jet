# ADR 0001: Portable project and log path resolution

## Context

`tools/measure-run.py` должен находить логи Claude для проекта при запуске из любого текущего каталога и одинаково работать с Windows- и POSIX-путями. Имя каталога логов строится не по правилам локальной файловой системы, а по отдельному правилу кодирования Claude: двоеточие и каждый разделитель пути превращаются в `-`.

## Decision

Разделить разрешение путей на чистые операции: нормализацию абсолютного project path, кодирование исходной строки project path и построение logs root. Локальные файловые операции выполнять через `pathlib.Path`; `home` или logs root разрешать передавать явно, оставив `Path.home()` только production-default. Корень checkout получать через явный CLI-аргумент либо `git rev-parse --show-toplevel`, а не выводить из текущего рабочего каталога.

## Why

Смешение локальной семантики `Path` с форматом имени каталога Claude ломает Windows-пути и делает результат зависимым от cwd. Чистые функции позволяют независимо доказать преобразования `C:\\Users\\X` в `C--Users-X` и `/Users/x` в `-Users-x`, а также запускать `--check-only` без реальных пользовательских логов.

## Consequences

Измеритель получает детерминированное и тестируемое разрешение путей на Windows, Linux и macOS. Positional interface `<project> [session-id]` сохраняется, но все потребители должны передавать реальный project path, а не рассчитывать на cwd. Правило кодирования Claude остаётся отдельным контрактом и не может быть заменено обычной нормализацией `Path`.
